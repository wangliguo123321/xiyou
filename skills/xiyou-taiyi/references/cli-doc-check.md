# 正文 CLI 对表检查

已有明确 CLI 快照、需要重复核查技能正文中的命令与 flag 时，按需使用 `scripts/check_cli_docs.py`。它只读显式输入，不安装或发现 CLI，不生成快照、不联网，也不执行文档命令；调用者自行取得并固定可信快照。

## 输入与调用

使用 Python 3 标准库，无第三方依赖。命令表为 UTF-8 TSV，每行两列：完整命令路径、以空白分隔的允许 flag；两列之间必须是一个制表符。路径以目标根命令开头，逐级子命令以单个空格分隔；根命令及每级中间父路径必须各有独立行，缺行视为输入无效并退出 `2`。空行和以 `#` 开头的注释行忽略，重复路径的 flags 取并集，空 flag 列允许。

例如，下面的 `<TAB>` 代表实际制表符，须在调用前替换：

```text
sample<TAB>--help
sample item<TAB>--help
sample item show<TAB>--json --format -h
```

从技能目录执行，路径含空格时使用引号；可依次传入多个文档：

```sh
python3 scripts/check_cli_docs.py --surface "/资料/CLI 快照.tsv" --command sample "/资料/技能正文.md" "/资料/命令说明.md"
```

表是给定版本的静态快照，不能证明当前二进制、新版本或实际服务支持这些命令与参数。本辅助不校验参数值、类型或命令运行结果。

## 有限抽取与结果

- 检查 `sh`、`bash`、`shell` 三反引号围栏中从行首开始的目标命令，允许前导空白及 `$ ` 提示符；检查围栏外单反引号中的目标命令。忽略其他语言围栏、普通叙述及其他命令，根命令后须有非空、非反引号的 token，仅有尾部空白的根命令不识别、不计数。不保证多反引号等 Markdown 变体，需要人工核对。
- 行尾反斜杠续行合并后检查，诊断使用最后物理行的行号；没有结束行的续行不检查。先将成对单双引号内容视为参数，再截去空白后 `#` 注释及 `|`、`;`、`&`、`>` 后片段。保留源检查器的此项窄词法，不支持引号转义、嵌套、命令替换、管道后命令或完整 shell 语义。
- 按表中已知路径逐级识别子命令。命令组后的小写开头未知词报 `unknown-command`；叶节点后的普通词视为参数。剩余的 `-` 开头词去掉 `=值` 后，与已识别完整路径的 flags 核对；引号内的伪 flag 不参与核对。
- 标准输出为单一 JSON 对象：`checked_commands` 为原始片段进入有限检查的次数，`diagnostics` 为按输入与扫描顺序排列的诊断数组，每项包含原输入路径 `file`、1 基物理行 `line`、`kind`、已识别路径 `command`、未知词或 flag `token`。
- `checked_commands` 在规范化前计数，包含随后被截为根命令或模板的片段；它不代表完整 CLI 验证数。没有诊断时退出码为 `0`，有诊断为 `1`；参数、表或文档读取/格式无效时向标准错误输出说明并退出 `2`，不输出部分检查结果。`checked_commands: 0` 只表示未抽取到可检查片段，不能据此宣称正文或 CLI 全部正确。

实测目标限定为固定源 `wayglass/wayglass-skill@4958b201766d53610731dcb9d0ae29fdfb13d108` 的原生 TSV 与六份技能正文/引用；验收需单独核对输入身份、抽取范围、诊断和退出状态。上游同提交 CI 曾消费其 `check.sh`，这只支持来源具有实际消费者，不等于本仓库 CI、当前二进制验证或本辅助已通过验收。
