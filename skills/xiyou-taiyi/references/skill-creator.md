# 创建、比较与改进

> 基于公开上游的中文适配；来源、固定版本和许可证见 [上游致谢](lineage.md)。

## 理解意图与选择基础

确定任务、触发条件、输入输出、实际约束和成功标准。优先使用本次明确提供的上下文；已有上游先固定快照，再修改或组合。创建职责清晰的 SKILL.md，把条件性细节放入引用资源。脚本只用于确实需要可靠重复执行的步骤。

## 起草与评测

先构造代表性任务和可观察的验收点。候选生成后在隔离环境运行：更新技能以旧版为基线，新的衍生角色以上游能力为基线，必要时再加无技能基线。同题、同输入、同模型设置，写作者不向执行者透露预期答案。

对结构、实际文件与结果做客观核查；对教学、解释或方案质量可用独立盲评，比较输出时隐藏版本身份。保留各案例结果、耗时及可取得的 token 数据；缺失指标记未知。复查总体分数是否掩盖退步或无区分度案例。

## 有依据地修改

按失败行为找原因，做窄范围改进，避免对一题过拟合。保留未用于改写的相邻问题。仅在目标收益存在、关键能力未退步时采用；没有改善就停止。结构验证只证明格式，不证明效果。

## 交付与更新

提供真实差异、来源、版本、依赖和必要使用示例。采用显式调用；Codex 的 allow_implicit_invocation 设置为 false。原始材料、适配稿和许可均可追溯。

## 西游适配

保留意图、候选、基线比较、独立评测与迭代；不依赖 Claude 专属 CLI、模型名、全局 hooks、强制 HTML 评测界面或固定分数。没有独立执行能力时只报告静态审查/自测，不以它证明相对效果。评测使用隔离目录；清理临时资源，保留项目约定要求的正式测试与结果。
