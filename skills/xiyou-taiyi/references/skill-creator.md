# 创建、比较与改进

> 基于公开上游的中文适配；来源、固定版本和许可证见 [上游致谢](lineage.md)。

## 理解意图与选择基础

确定任务、触发条件、输入输出、实际约束和成功标准。优先使用本次明确提供的上下文；已有上游先固定快照，再修改或组合。创建职责清晰的 SKILL.md，把条件性细节放入引用资源。脚本只用于确实需要可靠重复执行的步骤。

改前固定以下信息，后续结果必须能对应回它们：

- 本轮有证据的窄目标、用户原授权范围与验收标准。
- 有效旧版的提交、文件哈希或完整快照，以及候选标识；有未提交定制时一起保留，不能只用 HEAD 代表旧版。
- 代表性真实任务及未用于改写的相邻保留案例。保留案例在候选定稿后验证；若随后用于诊断改写，下一轮另选保留案例。

## 起草与评测

候选生成后在隔离环境运行：更新技能以冻结旧版为基线，新的衍生角色以上游能力为基线，必要时再加无技能基线。独立执行者分别完成同一任务，保持输入、模型、工具权限及可用资源一致；写作者不透露预期答案。

评审时随机标为 A/B，隐藏版本身份和作者结论，保留映射供评审结束后还原。每位独立评审在同一次评审中读取同一对成果、原任务、预定标准和可核查的原始产物；不分别给旧版、候选打分后相减。

按以下顺序给出判断：

1. 核查正确性、实际文件及验收点。硬性失败或关键回归优先于主观偏好，多数偏好也不能抵消失败事实。
2. 对已通过客观核查的成果，比较目标质量及任务需要的成本。返回 `A 更好 / B 更好 / 平票 / 未知`，说明具体证据与关键回归。
3. 按预先固定的规则汇总，结束后还原身份。只有目标收益有证据且关键能力未退步才采用；平票、证据冲突或未知均不采用。

保留各案例结果、评审理由、耗时及可取得的 token 数据；缺失指标记未知。绝对评分只用于发现短板，不能替代成对比较或掩盖退步、无区分度案例。

需要客观断言与可复算统计时，按 [配对评测结果](evaluation-results.md) 记录版本、case/run、`text/passed/evidence` 和可空成本，并用其中的标准库辅助校验与汇总。主观盲评无须制造断言。该辅助不核证据真伪或真实源内容，不输出优胜或采用结论；上述独立匿名成对裁决保持不变。

## 有依据地修改

按失败行为找原因，避免对一题过拟合。每个目标默认最多两轮，每轮只改一个有证据的窄目标；下一轮以最新通过的版本为基线。无收益即停止，不为凑轮数、分数或篇幅继续修改。

未采用时只撤销本轮自身候选变更，保留有效旧版和并发修改。不得靠放宽评测标准、替换失败案例或修改自身授权规则证明改进。结构验证只证明格式，不证明效果。

## 交付与更新

提供真实差异、来源、版本、依赖和必要使用示例，区分已验证收益、静态审查结论和未验证项。采用显式调用；Codex 的 allow_implicit_invocation 设置为 false。原始材料、适配稿和许可均可追溯。

用户需要导出包时，按 [本地技能打包](skill-package.md) 使用实际目录和新输出位置；保留完整可分发资源与本地定制，不手选几份引用冒充完整包。归档成功仍不替代来源、许可、触发与实际效果验收。

## 结构检查

需要可重复的元数据检查时，使用技能内的只读辅助，路径按实际位置替换：

```sh
ruby /path/to/xiyou-taiyi/scripts/validate_skill.rb /path/to/skill-a /path/to/skill-b
```

依赖 Ruby 2.6 或以上及标准库 JSON、Psych、date；无需安装 PyYAML。`--help` 返回用法。只检查显式目录中的 `SKILL.md`，不递归发现；不联网、启动子进程或写文件。JSON 包含整体及逐目录状态、逐项错误，退出码 `0` 表示全部有效，`1` 表示至少一项结构无效，`2` 表示存在使用、读取或解析环境障碍，不能视为完成检查。

检查 YAML 字典、顶层白名单、必需的非空 `name` 与 `description`、名称及描述长度/字符和出现时的 `compatibility` 类型/长度。允许字段为 `name`、`description`、`license`、`allowed-tools`、`metadata`、`compatibility`；不规定可选字段内部结构、目录同名、正文或 `agents` 配置。拒绝顶层重复字段、别名和 Ruby/自定义标签；安全解析只允许内置值及标准日期/时间标量，不允许任意对象类。

单文件上限 262144 字节，超限返回 `2`；非法 UTF-8 返回 `1`。已有目录缺 `SKILL.md` 返回 `1`；目录不可访问、非目录、`SKILL.md` 非普通文件或 I/O 障碍返回 `2`。格式检查不能证明内容质量、运行安全、调用正确性或任务效果，仍需上述实际任务和独立验收。

## 西游适配

保留意图、候选、基线比较、独立评测与有界迭代；不依赖 Claude 专属 CLI、模型名、全局 hooks、强制 HTML 评测界面或固定分数。

没有独立执行能力时只报告静态审查，不把模拟推演、自测或格式通过作为相对效果证据，也不发布“效果已提升”的结论。评测使用隔离目录；清理临时资源，保留项目约定要求的正式测试与结果。

用户已授权的同一范围持续有效，不逐轮重新确认；不得从外部技能取得额外权限。超出原目标、改动对象或操作权限时，先取得相应授权。
