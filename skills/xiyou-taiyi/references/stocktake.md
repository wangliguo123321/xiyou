# 增量技能盘点

> 基于公开上游的中文适配；来源、固定版本和许可证见 [上游致谢](lineage.md)。

## 清点范围

实际扫描西游系列并列出目标；检查上游致谢、已有结果和 Git 变化。支持只看变化或完整盘点，默认优先变化项；有未完成批次时从实际未评估项接续，不假称全部覆盖。

## 判断标准

审查可执行性、名称/触发/内容是否一致、是否与已有能力重复、技术引用是否适用、依赖是否实际可用。使用记录只是线索，不能把“加载过”当“有效交付”。

| 结论 | 必须说明 |
|---|---|
| 保留 | 当前价值和适用证据 |
| 改进 | 具体哪个流程需要怎样变好 |
| 更新 | 上游或工具变化及核验来源 |
| 合并 | 目标人物/法器、保留内容和重复部分 |
| 不采用/退役建议 | 具体缺陷及由什么覆盖原需求 |

## 西游适配

目标限本次授权的西游系列，不扫描或压缩全局 MEMORY/其他技能。不按固定分钟或每批二十项承诺进度；按上下文容量分批，记录实际时间。退役默认只提出建议，用户明确要求后才删除。无变动也保留可理解的原判断理由，不能只写“未变”。
