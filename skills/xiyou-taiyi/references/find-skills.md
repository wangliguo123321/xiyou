# 热门上游技能发现

> 基于公开上游的中文适配；来源、固定版本和许可证见 [上游致谢](lineage.md)。

## 理解需要

识别任务领域、具体问题与复用场景。已有角色是什么、缺哪项能力先讲清。

## 发现候选

先查 skills.sh 等可用目录和官方/热门原始项目；用具体中英文关键词检索，必要时换同义词、限定作者或领域。可用时沿用 Vercel Skills CLI 的 `skills find`，工具缺失可用现有网页/GitHub 工具，不为检索自动安装整套依赖。

## 核验与呈现

回到源仓库读实际 SKILL.md 与必要资源，核对原路径、版本、许可证和依赖。展示来源、适配原因、已知缺口和建议归属。热度用于排序候选，决定采用仍看内容及真实任务效果。

需要可重复的多文件取源时，可用 [只读取源辅助](source-inspection.md) 先固定完整提交、正文和内容哈希；仍需逐项核验作者、许可及方法，不把采集成功当成采用资格。

## 西游适配

保留热门入口、具体搜索和原始来源核验，去掉绝对下载/Stars 门槛及把热度当“实战证明”的推断。用户要求炼化时进入候选适配流程，不执行全局 `skills update` 或把整个第三方仓库自动安装。没有合适来源时报告搜索范围与缺口，不虚构已有实现。
