# 本地技能打包

仅在用户要求导出本地技能包时使用。输入是一个实际技能目录，输出是全新的 ZIP 格式分发文件；通常使用 `.skill` 后缀。不联网、安装、发布或修改源文件。不会按输入目录选择程序：元数据检查只用本工具随附固定位置的校验器，其余待打包文件只作数据。

```sh
python3 scripts/package_skill.py --skill-dir /path/to/xiyou-shaseng --output /path/to/existing-output/xiyou-shaseng.skill
```

依赖 Python 3.9 或以上、现有 Ruby 2.6 或以上及本工具同目录的 `validate_skill.rb`；只用标准库，不安装 PyYAML。单独拷走此脚本而漏掉校验器会失败。输出父目录必须已经存在。已有输出，包括符号链接，均拒绝覆盖；输出不能位于源目录或其子目录内。不要用用户原有压缩包作试验输出。

## 完整性与边界

- 读取当前实际目录，保留本地未提交或未跟踪的可分发文件，不用 Git HEAD 冒充本地定制。包内顶层是源目录名，下面保留相对路径、文件字节和 ZIP 中的权限属性；提取权限仍取决于宿主。
- 捕获 `SKILL.md` 的字节后，在已确认源外的输出父目录创建私有影子，用随本工具提供的校验器核该份内容；不从输入目录加载校验脚本，不使用可能先探测源目录的默认临时目录。随后收集整个可分发目录，不手工挑选引用文件。成品在私有目录中回读包成员及内容核对，不只看 ZIP 文件是否存在。
- 跳过任意层级的 `.git`、`__pycache__`、`node_modules`、`.DS_Store`、`.pyc` 文件，以及根目录的 `evals`。被排除的目录不遍历；其它已有文件不会因含 `test` 或 Markdown 名称而删除或漏选。排除仅作用于包，不删除源文件。
- 分发范围只接受普通文件和目录，拒绝源根或成员的符号链接、特殊文件，以及不能表示为 UTF-8、含控制字符、反斜杠或危险相对路径的名字。不会自动跟到源外目录。
- 结构检查不证明正文、`agents` 配置、引用闭包、作者许可齐备或技能效果正确；会携带源目录中实际已有的声明和许可，不自动补造或认证它们。确认源内容适合分发仍是调用者的责任。
- 跨文件为 `sequential_non_atomic` 读取，不是多文件原子快照，也不保证对抗恶意并发目录替换。需冻结版本时先使用稳定目录；工具检测到读取期间的文件或目录变化会失败，不能只拿某个 Git 提交代替包内实际字节。

最多遍历 4096 个目录条目、纳入 2048 个文件、总读取 32 MiB、分发路径深度 64。元数据上限为 262144 字节，Ruby 校验最多 10 秒；超限不会自动扩大。`--help` 提供普通帮助文本。

## 结果与失败

完整参数调用后输出一份 JSON，包含 `status`、`exit_code`、源/输出路径、包的格式/字节数/SHA256、各成员路径/字节数/SHA256、排除项与错误。成员路径带顶层目录。调用者应同时核实际退出码和状态，不能把保留的成员清单或文件存在当成成功。

| 状态与退出码 | 含义 |
|---|---|
| `success` / `0` | 元数据结构校验通过，包与本次读取的可分发文件核对一致。 |
| `invalid` / `1` | 无效元数据、不支持的源对象、名字或资源范围。 |
| `error` / `2` | 读取/ZIP/Ruby依赖障碍、已有或源内输出、检测到内容变化等，未完成打包。 |

参数非法可由 argparse 向 stderr 报错并退出 `2`。验证完整成品后，使用同文件系统硬链接原子地独占发布；目标已存在或文件系统不支持该操作就失败，不降级为覆盖写入。失败仅清理私有临时工作目录，从不删除最终输出路径，因此不会用检查后再删除的方式回滚别人的替换文件。发布之后的外部替换不归本工具回滚。

用户主动终止、操作系统强制结束或外部权限变化不保证完整 JSON 或临时目录回收；已发布的完整包不会因私有清理障碍而被删除。调用者仍应核状态、原始包与摘要，不能把文件存在当成全流程成功。归属不明时保留并说明，不以管理员权限绕过。

ZIP 格式和 `.skill` 后缀不等于已安装或获得所有宿主兼容性认证。单次完整目录复制或归档本来可以正确完成；此入口提供可重复调用的校验、选取、导出和明确失败边界，不声称提高模型一般能力。
