# PDF 逐页渲染证据

为已有 PDF 建立可回读的页面图像与清单，供任务交付或后续审阅使用。需要同一内容身份、明确页范围和逐页产物对账时使用；已有宿主能力提供等价证据时优先复用。

依赖 Python 3.9+ 标准库和 PATH 中已安装的 Poppler `pdfinfo`、`pdftoppm`。缺少工具就报告缺项，不自动安装。该法器不生成或编辑 PDF，不抽取文字、不做 OCR，也不判断版式合格或 PDF 安全性。

从本技能目录运行，给定普通本地 PDF 文件，以及父目录已存在、目标尚不存在的输出目录：

```bash
python3 scripts/render_pdf_pages.py --input /path/to/report.pdf --output-dir /path/to/new-pages
python3 scripts/render_pdf_pages.py --input /path/to/report.pdf --output-dir /path/to/new-selection --pages 1,3-5 --max-edge 1600
```

`--pages` 默认 `all`，显式页码从 1 开始；重复项去重、升序处理，拒空项、逆序及越界。每次最多渲染 20 页；更多页的文件可分批选页，每批使用新目录。`--max-edge` 默认 1600，范围 256..2400，是请求的图像最长边像素上限，不是 DPI 或清晰度合格线。输入最大 25 MiB。单次工具最多 15 秒，整次调用的工具预算最多 120 秒；这是有限调用上限，不是恶意 PDF 的安全隔离保证。输入符号链接、已有输出位置、缺工具、坏或未解锁 PDF、页数字段歧义、无效范围与配额错误均不能当成功；元数据可能伪装页数，歧义时不猜总页数。

输入按有界内容快照渲染，清单的 SHA256 与字节数对应实际交给渲染器的内容。原 PDF 不改写；一次调用不持续追踪源文件后续修改。输出 PNG 按原页号对应，清单记录原 PDF 总页数、请求页码、是否覆盖全篇、实际 PNG 宽高及 SHA256。`manifest.json` 与标准输出提供同一机器结果；失败时准确保留本次已有的页面清单，不混用旧图或覆盖已有目录。

`status=complete` / 退出 0 只表示请求页的图像齐备；`partial` / 退出 2 表示只有部分请求页成功；`error` / 退出 1 表示失败且无可用页。命令行参数错误同样不能视为成功。选页齐备不代表整篇已渲染。`visual_review=not_performed` 始终提示仍须看图，图片或清单存在不能证明没有缺字、重叠、裁切或表格溢出。

读取清单后实际打开所需 PNG，核中文、页码、图表、页眉页脚及跨页变化；交付整篇时应检查全部页。发现问题交回产物作者修订，之后对最新 PDF 重新渲染，不能沿用旧图结论。文字抽取可帮助核文字，但不能替代页面视觉核验。只清理本次明确归属的中间产物，保留用户要求交付的页面与清单。
