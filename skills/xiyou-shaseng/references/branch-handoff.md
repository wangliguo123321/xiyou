# 分支交付检查

> 基于 Superpowers `finishing-a-development-branch` 适配；固定来源与许可见 [上游致谢](lineage.md)。仅在用户要求分支交付、PR 或工作树处理时加载。

## 先读状态，再执行已选动作

核实当前分支或 detached HEAD、工作树位置与归属、未提交和暂存内容、需要保留的产物；目标分支与比较基点以任务、上游配置和实际历史为依据。缺少影响合并或推送的关键信息时，仅暂停相应动作并保留现场。

把验证证据与将要交付的代码状态对应；需要合并时核对合并后的行为。已有提交、推送或 PR 授权就执行，不强制再次展示菜单。普通“帮我收尾”不自动变成提交、合并或删除任务。

## 保留与清理

PR 创建后通常还需要接续评审，保留相应工作树与分支。删除只作用于明确授权、归属已核实且不存在唯一未保存内容的对象；目录名像 `worktrees` 并不能证明本任务拥有它。遇到未知修改、宿主管理工作树或清理失败，保留状态并报告。

输出实际完成动作、提交或 PR 链接、验证边界、保留位置及未完成事项。没有要求集成交付时记录现状即可。

## 西游适配

保留状态探测、交付验证与保留原则，不继承固定三选菜单、默认全套测试、按目录名认领工作树或自动删分支。提交、PR、合并和删除分别沿用用户当前授权。
