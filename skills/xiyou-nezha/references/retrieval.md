# 渐进检索

> 基于公开上游的中文适配；来源、固定版本和许可证见 [上游致谢](lineage.md)。

## 查询 → 评估 → 修正 → 停止

1. 从用户提供的符号、路径、症状和项目范围形成初始查询；线索稀少时再扩大关键词。
2. 按实际内容判断结果：直接实现目标、相关调用/类型、旁支、无关。记录还缺少的关键上下文。
3. 学习项目实际术语，把已发现入口与缺口转成更精确的下一次查询，排除确定无关的路径。
4. 合并有效证据，足以回答即停止。通常在少数检索轮内给出结果或明确缺口；不把循环次数当成正确性的替代。

## 西游适配

继承上游渐进修正和缺口驱动，改为当前主代理可直接执行。无需先创建检索子代理或 RAG 管道，不强求三个文件、数值相关性分数或固定循环。源码事实明确后，输出短结论及可复查位置。证据不足时返回局部确定结论和最小补充项。
