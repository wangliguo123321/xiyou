# 离线流程图制作

用于把已核实的分支和操作顺序交付为可编辑 SVG。先核源码/材料的条件和出口，再制图；普通讲解不强制成图。架构、时序、科学绘图和品牌插画不套这个有限流程图接口。

## 制作方法

1. 列出实际步骤、条件、出口和不确定处。缺事实先标明或核查，不为凑图编路径。起止用胶囊形、操作用圆角矩形、判断用菱形；每条判断出口用文字标明条件，不只靠颜色。
2. 选择一个主流向，以 4px 网格安排节点。复杂图先拆分并明说省略内容；同一节点的连接端口分开，显式布置水平/竖直折线，避开无关节点。标签与线/边框留约 6–10px 净空；多个端口不要重叠。
3. 保留文字为原生 SVG text。汉字按全宽估算，较长内容先分行或放大节点。使用系统字体，不下载或嵌入字体。必要图例放单独底栏；本接口四种图元通常无需另设图例。
4. 用下列接口生成新 SVG。它负责有限结构、转义和可重复图元制作，**不做自动布局或完整碰撞检查**。坐标与真实字体是否合适仍由实际看图判断。
5. 用宿主已有的 SVG 渲染工具生成 PNG 并逐图查看，核关系/出口、中文、文字裁切、标签净空、线是否穿过无关节点。无渲染链就说明尚未视觉验收，不称版面通过；不自动安装。交付 SVG，按需附 PNG；保留用户的正式产物，只清本次临时资源。

## 制作接口

Python 3 标准库，无第三方运行依赖。路径相对本技能目录：

```bash
python3 scripts/make_flowchart.py --input /path/to/scene.json --output /path/to/diagram.svg
```

参数通常由 Agent 准备，用户无需手填坐标。输入为 UTF-8 JSON，输出父目录需已存在；只创建新文件，已有文件或符号链接一律不覆盖。需修改成图时使用新路径。失败退出码 2、中文错误写入 stderr，无部分 SVG。

| 层级 | 字段与限制 |
|---|---|
| 图 | `title`、`description` 为非空字符串，各至多 2048 字符；作为可访问元信息，不自动画到画布。`width`、`height` 为 160–4096 像素；`nodes` 为 1–30 节点，`edges` 至多 60 条；JSON 至多 1 MiB |
| 节点 | `id` 字母开头、1–48 位 ASCII 字母/数字/`_`/`-`；`shape` 仅 `start` / `process` / `decision` / `end`；`x,y,w,h` 显式坐标与尺寸，宽至少 48、高至少 32，距画布边至少 8px；`label` 为 1–6 非空行、合计至多 512 字符，仅用 `\n` 分行 |
| 连接 | `from,to` 引用节点 id；`points` 为 2–32 个 `[x,y]`，相邻点构成非零水平/竖直线段，首尾落在对应图元轮廓上并避圆角，距画布边至少 8px |
| 出口标签 | 可选 `label,label_x,label_y` 须整组提供；每个判断至少两条带文字标签的出口。坐标是标签中心；标签行数/长度同节点 |

拒绝未知/重复 JSON 字段、重复节点、非有限数值和无效引用。固定 16px 字体、22px 行距，按 CJK 1em/其他字符约 0.7em 留保守空间；判断文字按中心半宽/半高预算，放不下会要求分行、放大或精简。预算不是字体测量，不保证所有字形兼容，也不保证语义正确、节点无重叠或路线避障。

最小示例：

```json
{
  "title":"结果判断","description":"检查已完成后，按结果展示成功或失败。",
  "width":720,"height":400,
  "nodes":[
    {"id":"check","shape":"decision","x":200,"y":24,"w":320,"h":160,"label":"检查通过？"},
    {"id":"ok","shape":"end","x":52,"y":280,"w":180,"h":64,"label":"展示成功"},
    {"id":"fail","shape":"end","x":488,"y":280,"w":180,"h":64,"label":"说明失败"}
  ],
  "edges":[
    {"from":"check","to":"ok","points":[[200,104],[142,104],[142,280]],"label":"是","label_x":142,"label_y":206},
    {"from":"check","to":"fail","points":[[520,104],[578,104],[578,280]],"label":"否","label_x":578,"label_y":206}
  ]
}
```

输出无脚本、外链、图片或字体字节；节点 `node-<id>` 与顺序边 `edge-001` 等便于后续编辑。同一输入重复生成字节一致，只改标签时关系和几何不变。SVG 可独立打开或用已有工具栅格化；只将自己生成的静态图交给渲染器，不把外来 HTML/脚本当同等安全输入。
