# 教学 Notebook 制作

> 改编自 OpenAI 历史公开 `jupyter-notebook` Skill 的教学模板方法；固定来源及 Apache-2.0 见[上游致谢](lineage.md)。原库已弃用，不代表当前官方插件的维护或许可。

## 用途与产物

用户需要一个待填写的 Python 教学 `.ipynb` 时，先确定标题、读者、目标及保存位置。用随技能的中文模板创建骨架，避免每次重新手写 Notebook 外壳；然后再填写真实讲解、代码和结果。只创建七个有序单元格：目标与先决条件、提纲、设置代码、小例子说明、例子代码、练习、答案代码骨架。

没有完整课程内容时保留明确的“待填写”，不把骨架交付称为教程已完成。已有 Notebook 的编辑、输出清理、实验模式及执行不属于此辅助。

## 新建文件

依赖 Python 3.9 以上及标准库。显式指定已存在父目录下的全新绝对路径：

```sh
python3 /path/to/xiyou-tangseng/scripts/create_tutorial_notebook.py \
  --title 'Python 列表推导式入门' \
  --output /已有目录/lesson.ipynb
```

标题须为单行非空 UTF-8 文本，最多 200 个字符，无控制字符；保留输入字符，不自动裁剪或归一化。脚本从固定的 `assets/tutorial-template.json` 制作 Notebook 4.5，保留单元格顺序与唯一 ID、Python 3 语言元数据，不填写实际内核版本。代码单元格只有待填注释，`execution_count` 为 `null`，`outputs` 为空。

不自动创建父目录、覆盖目标或提供 `--force`；已有普通文件、目录、软链接都不能替换。发布新文件需要父目录支持普通文件及硬链接：同目录临时文件写完后独占链接到目标，再删除本次临时文件。文件系统拒绝操作时报告错误；遇到发布后的清理错误，应先核对目标是否已生成，不直接重试。

退出 `0` 时，stdout 是 JSON，包含 `status: created`、`output` 的绝对路径/实际字节数/SHA256、`notebook` 的格式与 7/3 单元格计数，以及 `execution: not_performed`。`--help` 返回用法并退出 `0`。参数、模板或文件障碍退出 `2`，stderr 是中文 JSON 错误，不应视为交付成功。模板结构检查只保护此固定骨架，不是通用 Notebook 校验器。

## 填写与验证

讲解与短代码分开放，先用小规模输入说明一个规律，再给变式、常见错误与练习。填写后检查单元格顺序、内容及真实结果；需要运行时，只在用户允许且已有相应环境时从头到尾验证。环境不可用就注明未运行，不安装依赖或伪造执行计数。

本辅助不联网、不启动内核或执行代码单元格。生成和原生 JSON 消费不等于完整 JSON Schema 引擎校验、Jupyter 前端打开或内核运行通过。空输出也不证明课程正确、可复现或用户已掌握。

## 西游适配

保留原教学模式、模板优先和未运行状态，改为中文占位、显式新路径、唯一合法 cell ID 与机器可消费的文件身份；移除默认仓库输出、自动建目录、覆盖选项、固定 Python 版本声明及原示例代码。上游脚本与代码单元格没有执行。
